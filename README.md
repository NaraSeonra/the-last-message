# THE LAST MESSAGE

Game misteri interaktif berbahasa Indonesia di dalam smartphone Android virtual. Pemain menjadi Nara, siswi SMA yang menerima pesan dari nomor sahabatnya yang hilang.

**Teknologi:** TanStack Start, React 19, TypeScript, Tailwind CSS 4, Web Audio API, localStorage, Netlify (Image CDN untuk gambar).

**Menjalankan lokal:** `pnpm install` lalu `pnpm dev` (atau `netlify dev`).

**Roadmap:** lihat [PLAN.md](PLAN.md). Mesin cerita dan seluruh konten sudah ada; antarmuka ponsel dan aplikasinya berikutnya.
